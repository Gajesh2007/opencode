Run a concurrent, multi-lens code review and return the synthesized report.

Scope: $ARGUMENTS

---

Interpret `$ARGUMENTS` as the review scope:
- empty → all uncommitted changes (staged, unstaged, and untracked)
- `staged` or `pr` → staged changes
- `commit <sha>` → that specific commit
- `branch [name]` → diff against the base branch (this repo's default branch may be `dev`, not `main`)

Steps:

1. Resolve the scope and list the changed files with git, then drop deleted, generated, vendored, lockfile, and binary paths.
2. Make a single `workflow` call that fans out three read-only lenses — `review-security`, `review-logic`, `review-style` — over every remaining file, with `review-synthesizer` as the synthesis step and `format: "findings"`. Do not loop file-by-file; one call reviews all files concurrently.
3. Return the synthesizer's ranked Markdown report. A large change set is fine but may take a while and be token-intensive.

Your full operating contract is in the `review` orchestrator system prompt.
